# agents/

Custom agents generados desde este repositorio. **Ningún `.md` entra aquí sin cumplir la
baseline.**

- Norma obligatoria: [`../governance/baseline-mandatory-instructions.md`](../governance/baseline-mandatory-instructions.md)
  — checklist de autoverificación (Apartado 8) superada antes de entregar.
- Comportamiento aplicado: [`../comportamiento/perfil.md`](../comportamiento/perfil.md).
- Convención *(por defecto)*: un fichero `<name>.md` por agente y, cuando aplique, su política de
  herramientas en `<name>.policy.yaml`.

Todo agente será auditado por el **Agents Governance Gate** (controles `BBVA_ASI01_*`,
Apartado 6 de la baseline); un bloque obligatorio ausente ⇒ KO y PR de despliegue bloqueada.
